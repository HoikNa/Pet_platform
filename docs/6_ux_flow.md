# 6. UX Flow 및 예외 처리 정책

## 1. 개요
고객 온보딩 과정부터 주요 과제인 '생체 등록' 및 '헬스 스캔'까지의 화면 전환 플로우와 발생 가능한 모든 실패 케이스에 대한 대응 기획을 정리합니다. 유연한 예외 처리로 앱 이탈을 시키지 않는 것이 목표입니다.

## 2. 주요 시나리오 UX Flow

### 2.1. 사용자 인증 및 가입
1.  **[Landing View]:** 서비스 가치 제안 캐러셀 표시.
2.  **[Action]:** '카카오로 3초 만에 시작하기' 버튼 터치.
3.  **[Auth View]:** OAuth 인증 후 서버 검증.
4.  **[分岐1 - 신규유저]:** 반려동물 유무 확인 팝업 -> '등록하기' 진행 (2.2 플로우 진입).
5.  **[分岐2 - 기존유저]:** 메인 대시보드 리다이렉트 (목록 출력).

### 2.2. 반려동물 생체 등록 (Zero-Cost Registration)
1.  **[Pet Form View]:** 동반자 이름, 성별 등 기본 메타 입력.
2.  **[Camera Guide View]:** "안정된 곳에서 안면이 보이게 해주세요" 화면 안내 및 마스킹 오버레이 노출.
3.  **[Action]:** 버튼 터치 시 영상 녹화 임시 저장.
4.  **[Loading View]:** S3 업로드 스피너 노출 및 "분석 & 등록 진행 중..." 텍스트 애니메이션 적용.
5.  **[API 응답]:** -> 성공 시: 폭죽 애니메이션을 띄우며 메인 대시보드 진입. 실패 시 예외 처리 적용.

### 2.3. AI 헬스 스캔 리포트 확인
1.  **[Main Dashboard]:** 보유 중인 반려 동물 카드 리스트에서 특정 동물 클릭.
2.  **[Pet Detail View]:** 하단 '새로운 건강 스캔 시작' FAB 버튼 클릭.
3.  **[Scan Options View]:** BCS/노화(검안) 분석 등 목적 선택. 가이드 영상 시청 (모범 스캔 사례).
4.  **[Camera View -> Upload View]:** 분석 요청 후 로딩 인디케이터 표시(분석이 긴 경우 Push 알림을 약속하고 페이지 귀환 유도 가능성 부여).
5.  **[Report View]:** 분석 완료 후 인포그래픽, BCS 점수 및 코멘트 노출. 하단 B2B IR/추천상품 등 CTA 버튼 구성.

### 2.4. B2B/B2G 관리자 포털 조회 (Admin CRM Flow)
1.  **[Admin Dashboard]:** 병원/지자체 계정 로그인 후 소속 기관에 연동된 환축 전체 목록 Data Table 조회.
2.  **[Filter & Search Action]:** 특정 환축의 보호자 이름 혹은 생체 식별 ID로 검색 및 필터링 시도.
3.  **[Detail EMR View]:** 환축 클릭 시 기존 원내 EMR 데이터와 플랫폼의 AI 헬스 리포트가 결합된 통합 뷰 노출.
4.  **[예외 처리 - 인가 실패]:** 권한이 없거나 만료된 계정 접근 시 "관리자 권한이 필요합니다" Toast 메시지 노출 후 로그인 화면으로 강제 리다이렉트 처리.

## 3. 예외 처리 정책 및 회복 플로우 (Resilience)

### 3.1. 디바이스 권한 관련
*   **이슈:** 카메라 엑세스 권한 거부.
*   **회복:** 화면 중앙에 "스캔을 위해서는 카메라 권한이 필수입니다"라는 안내와 브라우저/시스템의 설정 화면으로 유도하는 안내 그래픽 제공. 임시로 프로필 데이터만 먼저 등록하는 fallback 플로우 허용 여부(추후 논의).

### 3.2. AI 스캔 및 이미지 품질 저하 (BIO_001, BIO_002 등)
*   **이슈:** 피사체 흔들림, 조명 어두움, 혹은 엉뚱한 물체.
*   **회복:** 서버에서 구체적인 에러 코드를 내려줌. 프론트엔드는 붉은 배너(Toast)로 "흔들림이 너무 심합니다" 와 같은 명확한 원인을 고지하고, 카메라 뷰를 닫지 말고 *Retake(재촬영)* 버튼을 화면 최상단에 띄움. 재촬영 과정 진입 허들을 낮춘다.

### 3.3. 네트워크 단절
*   **이슈:** 모바일 데이터 불안정으로 업로드 중단.
*   **회복:** "인터넷 연결이 불안정합니다. 임시 저장되었습니다." 토스트 팝업 (Local Storage 활용 저장 방안 옵션).

### 3.4. 데이터 지연 (백엔드 큐 대기)
*   **이슈:** 보행 분석 시 API 응답 대기 시간이 오래 소요됨.
*   **회복:** Timeout 경고를 피하기 위해 프로그레스 바 대신 무한 로딩 + 재치 있는 멘트("강아지가 열심히 뛰고 있어요...")를 띄우거나, 백그라운드 처리로 전환 후 "결과가 나오면 알림을 드립니다"라는 안내와 함께 다른 메뉴 탐색을 유도.
